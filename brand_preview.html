Gradient, sampled from the artwork

Bottom-left indigo → top-right amber. The icon tile is flat #141417 on purpose: a gradient tile runs along the same axis as the ring, which makes the left half of the mark disappear.

Launcher icon — on a dark home screen

Launcher icon — on a light home screen

Adaptive icon layers (Android 8+)

The foreground holds the mark inside the 66dp safe zone of the 108dp canvas. The launcher masks up to 72dp, so anything past 66dp gets clipped on a circular mask.

Themed icon (Android 13+)

A separate silhouette, not the colour layer — the launcher replaces every pixel with the wallpaper palette. The near-white letterforms are punched back out so "LIVE" survives the tint.
